Personal website of Andrey Perestoronin, Python Backend Developer. Built with Jekyll.


## Development

Install dependencies:

```bash
bundle install
```

Run the development server:

```bash
bundle exec jekyll serve
```

Open:

```
http://127.0.0.1:4000
```

## Build

```bash
bundle exec jekyll build
```

Generated files will be available in:

```
_site/
```

## Deployment

The site is automatically built and deployed to GitHub Pages using GitHub Actions.
